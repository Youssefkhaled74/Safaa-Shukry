# Safaa Shukry · Chemistry portfolio

Responsive Arabic / English static website for GitHub Pages. No build step required.

## Preview

Run `npx --yes serve .` and open the local URL. All paths are relative so project-based GitHub Pages URLs work.

## Contact settings

Edit `config` at the top of `app.js` to add the public YouTube video/channel URL and email address. The phone number is taken from the supplied artwork. Booking prepares a WhatsApp message; the visitor must send it, and the teacher must confirm the booking. No form data is stored on this site.

The gallery contains historical announcements and does not claim those schedules are current.

## GitHub Pages

Push this folder to a GitHub repository with branch `main`. In repository Settings → Pages, set Source to GitHub Actions. The included workflow deploys on every push. Do not add a custom domain unless it is yours.
